# Mi Entrenamiento — app web/PWA

Esta carpeta está lista para publicarse como una página web estática.

## Opción recomendada: GitHub Pages

1. Crea una cuenta en GitHub si no tienes una.
2. Crea un repositorio nuevo, por ejemplo `mi-entrenamiento`.
3. Sube TODOS los archivos de esta carpeta, manteniendo la carpeta `.github/workflows/`.
4. Haz `Commit` en la rama `main`.
5. En el repositorio, entra en `Settings > Pages`.
6. En `Build and deployment`, selecciona `GitHub Actions`.
7. Espera a que termine el workflow `Publicar app`.
8. GitHub mostrará la URL pública de la app.

La URL tendrá una forma parecida a:
https://TU-USUARIO.github.io/mi-entrenamiento/

## En el móvil

Abre esa URL con Safari (iPhone) o Chrome (Android).

- iPhone: Compartir → Añadir a pantalla de inicio.
- Android: menú ⋮ → Añadir a pantalla de inicio / Instalar aplicación.

Después se abrirá como una app y puede funcionar sin conexión después de la primera visita.

## Datos

Los pesos, repeticiones e historial se guardan en el almacenamiento local del navegador del dispositivo.
No se envían a un servidor.

Si se borran los datos del navegador, se desinstala la app o se cambia de dispositivo, esos datos pueden perderse. Usa la opción "Exportar" de Ajustes para hacer copias de seguridad.
